# 敏感词实体自动隐藏功能

## 功能概述

当用户对识别到的敏感词实体进行操作后（添加到替换列表或删除），该实体会自动从上方的识别列表中移除，避免重复操作和视觉混乱。

## 功能特性

### 1. 添加后自动隐藏
当用户通过以下任一方式将敏感词添加到替换列表后，该实体会立即从识别列表中消失：
- 点击左上角的 ✓ 绿色按钮
- 点击标签主体（中间文字部分）

### 2. 删除后自动隐藏
当用户点击右上角的 ✗ 红色按钮删除误识别的实体后，该实体会立即从识别列表中消失。

### 3. 状态管理
- 使用本地状态 `localEntities` 管理当前显示的实体列表
- 每次操作后，通过 `filter` 方法移除对应的实体
- 状态变化立即反映到 UI

## 实现细节

### 代码实现

```typescript
// 添加到替换列表时，同时从识别列表移除
const handleQuickSelect = (text: string, type: string) => {
  setFeedback(null);
  const last = entries[entries.length - 1];
  if (!last.find) {
    setEntries(prev => prev.map(e => e.id === last.id
      ? { ...e, find: text, replace: TYPE_DEFAULTS[type] || '***MASKED***' }
      : e
    ));
  } else {
    setEntries(prev => [...prev, { id: uid(), find: text, replace: TYPE_DEFAULTS[type] || '***MASKED***' }]);
  }
  // 关键：添加后从识别列表中移除
  setLocalEntities(prev => prev.filter(entity => entity.text !== text));
};

// 快速添加按钮（左上角 ✓）
const handleQuickAdd = (text: string, type: string, e: React.MouseEvent) => {
  e.stopPropagation();
  handleQuickSelect(text, type);
  // 添加后从识别列表中移除
  setLocalEntities(prev => prev.filter(entity => entity.text !== text));
};

// 删除按钮（右上角 ✗）
const handleRemoveEntity = (text: string, e: React.MouseEvent) => {
  e.stopPropagation();
  // 从识别列表中移除
  setLocalEntities(prev => prev.filter(entity => entity.text !== text));
  if (onRemoveEntity) {
    onRemoveEntity(text);
  }
};
```

### 优势

1. **避免重复操作**
   - 已处理的实体不再显示
   - 用户不会重复添加相同的内容
   - 减少操作错误

2. **清晰的视觉反馈**
   - 操作后立即看到效果
   - 剩余的实体一目了然
   - 知道还有哪些需要处理

3. **提高效率**
   - 不需要记住哪些已经处理过
   - 专注于剩余的实体
   - 快速完成批量处理

4. **减少视觉混乱**
   - 识别列表逐渐变少
   - 界面更加整洁
   - 降低认知负担

## 技术要点

### 1. 状态过滤
使用 `filter` 方法移除已处理的实体：
```typescript
setLocalEntities(prev => prev.filter(entity => entity.text !== text));
```

### 2. 立即更新
状态更新后，React 自动重新渲染，用户立即看到效果。

### 3. 文本匹配
通过 `entity.text` 精确匹配要移除的实体，确保只移除目标实体。

### 4. 不影响原始数据
只修改本地显示状态 `localEntities`，不影响父组件传入的 `detectedEntities`。

## 边界情况处理

### 1. 所有实体都被处理
当识别列表为空时，显示提示信息：
```
未检测到标准 PII（手机号/身份证等）。
可在下方手动输入要替换的文本...
```

### 2. 重复的实体文本
如果多个实体有相同的文本（但类型不同），会同时移除所有匹配的实体。这是预期行为，因为用户通常希望处理所有相同的文本。

### 3. 关闭对话框后重新打开
- 本地状态 `localEntities` 会重置
- 所有实体重新显示
- 用户可以重新处理

## 性能考虑

### 1. 过滤性能
- 使用 `filter` 方法，时间复杂度 O(n)
- 对于通常的实体数量（< 100），性能影响可忽略

### 2. 重新渲染
- 只有识别列表部分重新渲染
- 替换列表不受影响
- React 的虚拟 DOM 优化确保高效更新

### 3. 内存占用
- 本地状态只存储当前显示的实体
- 已移除的实体被垃圾回收
- 内存占用随操作减少
