# 中文 PDF 处理指南

## 问题说明

您遇到的 `?Identity-H Unimplemented?` 错误是因为某些中文 PDF 使用了特殊的字体编码（Identity-H），而 PDF 解析库无法识别这种编码。

## 已修复 ✅

系统现在会自动检测这个问题，并尝试使用 OCR（光学字符识别）来提取文本。

**✨ 新功能：OCR 现在支持页码范围提取！**

## 使用方法

### 方法 1：不指定页码范围

1. 上传中文 PDF 文件
2. **不要填写页码范围**（留空）
3. 点击"开始脱敏"
4. 系统会自动：
   - 先尝试直接提取文本
   - 如果失败，自动切换到 OCR 提取
   - 处理整个文档

**优点**：
- 自动处理，无需手动干预
- 支持 OCR 回退
- 成功率高

### 方法 2：指定页码范围 ⭐ 推荐

1. 上传中文 PDF 文件
2. 填写页码范围（如 1-10）
3. 点击"开始脱敏"
4. 系统会自动：
   - 先尝试使用 lopdf 提取指定页面
   - 如果失败（如遇到 Identity-H 编码），自动切换到 OCR
   - **OCR 也会只提取指定的页码范围**

**优点**：
- ✅ 支持中文 PDF + 页码范围
- ✅ 自动 OCR 回退
- ✅ 节省处理时间
- ✅ 文件名包含页码：`文件名_脱敏_p1-10.txt`

**工作流程**：
```
上传 PDF + 指定页码 1-10
    ↓
尝试 lopdf 提取第 1-10 页
    ↓
成功？
    ↓
   是 → 返回文本 ✅
    ↓
   否 → 检测到 Identity-H 错误
    ↓
自动切换到 OCR
    ↓
OCR 提取第 1-10 页 ✅
    ↓
返回文本
```

## OCR 功能说明

### 什么是 OCR？

OCR（Optical Character Recognition，光学字符识别）是一种将图像中的文字转换为可编辑文本的技术。

### 何时使用 OCR？

系统会在以下情况自动使用 OCR：
- PDF 包含不支持的字体编码（如 Identity-H）
- PDF 是扫描版（图片格式）
- 直接文本提取失败

### OCR 支持页码范围吗？

**✅ 是的！** 现在 OCR 完全支持页码范围提取：
- 您可以指定任意页码范围（如 1-10, 5-20）
- OCR 只会处理指定的页面
- 节省处理时间和资源

### 如何安装 OCR？

如果系统提示需要安装 OCR 依赖：

1. **自动安装（推荐）**：
   - 点击界面上的"下载 OCR 依赖"按钮
   - Windows：自动下载嵌入式 Python 环境
   - macOS：创建本地 Python 虚拟环境
   - 等待安装完成后重新处理文件

2. **手动安装**：
   ```bash
   # 安装 Python 3.9+
   # 然后运行：
   pip install PyMuPDF
   ```

## 常见问题

### Q1: 为什么我的 PDF 显示 "Identity-H Unimplemented" 错误？

**A**: 这是因为您的 PDF 使用了特殊的中文字体编码。系统现在会自动尝试使用 OCR 来处理，无需担心。

### Q2: 我指定了页码范围，OCR 会处理整个文档吗？

**A**: 不会！OCR 现在支持页码范围，只会处理您指定的页面。例如，您指定 1-10 页，OCR 也只会提取第 1-10 页。

### Q3: OCR 处理速度慢吗？

**A**: OCR 比直接文本提取慢，但对于无法直接提取的 PDF，这是唯一的方法。处理时间取决于：
- PDF 页数（使用页码范围可以减少处理时间）
- 图片分辨率
- 计算机性能

**提示**：使用页码范围可以显著减少处理时间！

### Q4: OCR 准确率如何？

**A**: 对于清晰的中文文本，OCR 准确率通常在 95% 以上。如果 PDF 质量较差（模糊、倾斜），准确率可能降低。

### Q5: 我可以同时处理多个中文 PDF 吗？

**A**: 可以！系统支持批量处理。每个文件都会自动选择最佳提取方法。

### Q6: 页码范围的格式是什么？

**A**: 
- 格式：`起始页-结束页`（如 `1-10`）
- 页码从 1 开始计数
- 留空表示处理全部页面
