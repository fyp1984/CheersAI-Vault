# CheersAI Vault Pro · 操作手册

面向浏览器端使用者的简易指南。部署与技术细节见 [DEPLOYMENT.md](./DEPLOYMENT.md)（面向管理员）。

本版本按“单一系统用户”交付：能打开该页面的所有浏览器会话共享同一台服务器的状态（同一沙箱目录、同一个共享 PIN、同一套 FileBay 配置），不包含登录、账号或权限系统，见第 10 节。本版本仅面向企业内网使用。

## 1. 打开企业端

这是 CheersAI Vault Pro 企业浏览器入口（原 Vault 客户端经服务器适配后的页面），由管理员告知的地址在浏览器打开：

- Linux 内网客户测试部署：管理员告知的 Nginx 内网地址（例如 `http://<内网服务器地址>/`），需在客户网段内才能访问，其他网络无法打开。
- 本机开发调试：`http://127.0.0.1:3000`（仅本机访问；开发服务器通过 Vite 代理把 `/api` 转发到本机 Runtime）。

页面左侧是导航栏，包含「文件脱敏」「文件反脱敏」「文件管理」「FileBay 设置」「规则配置」「沙箱管理」「操作日志」等入口。

## 2. 提交文件（先预览、再确认）

1. 点击左侧「文件脱敏」。
2. 选择要脱敏的文件（支持格式与限制见第 6 节）。
3. 勾选需要识别的规则（手机号、邮箱、身份证号等）；敏感词库在「规则配置」页管理（见第 5.1 节）。
4. 点击「生成脱敏预览」，等待预览生成：
   - 预览页会显示每个文件的处理状态（生成中/已就绪/失败），以及已就绪文件的脱敏后内容预览。
   - 全部文件就绪或部分失败后，核对预览无误，再点击「确认并生成正式批次」提交为正式批次。
   - 全部文件失败时不能确认为正式批次，请取消预览、调整文件或规则后重试。
5. 确认后进入「操作日志」查看进度。

> 预览途中切换页面：预览在服务器上生成，切换页面不会打断它。回到左侧「文件脱敏」页会自动恢复同一份预览，请不要重复选择文件再点一次“生成脱敏预览”，否则会创建新的预览会话。

## 3. 查看结果

「操作日志」页中每个批次显示状态：

- 已完成：全部文件成功。
- 部分失败：批次内有文件成功、有文件失败，点「查看详情」逐个查看。
- 失败：全部文件失败，点「查看详情」→「查看错误与重试」可看到具体原因（错误码 + 一句话说明），可点「重新处理」重试。

## 4. 下载与恢复

- 成功的文件在批次详情页可「下载 Markdown」，得到脱敏后的文档。
- 需要看回原文时，进入「文件反脱敏」页面，勾选已完成的产物，点「开始反脱敏」即可下载还原后的文件。
- 映射数据（`.cmap`）只保存在服务器内部，页面上没有下载入口，不会被导出。
- 「文件管理」页集中展示服务器上已有的批次记录与处理结果，可搜索、按状态筛选，并在已完成批次中勾选脱敏 Markdown 上传到 FileBay（见第 9.2 节）。

## 5. 操作日志：搜索与筛选

「操作日志」页支持按批次 ID 前缀搜索、按状态筛选（全部/处理中/已完成/部分失败/失败），点击「清空条件」恢复完整列表。

## 5.1 规则与敏感词（「规则配置」页）

- 提交文件时勾选的是内置规则（身份证号、手机号、电子邮箱、银行卡号、IPv4 等）。
- 「规则配置」页还提供敏感词库：可在页面上维护自定义敏感词列表、分类与启用状态，支持 CSV 批量导入/导出（敏感词库保存在服务器上，同一服务器的所有会话共享）。提交批次时勾选“启用敏感词库”，已启用的敏感词即参与脱敏匹配。
- 敏感词未配置时不阻断任何功能；页面会明确区分“未配置已启用敏感词”与“加载失败”。

## 5.2 沙箱/PIN（「沙箱管理」页）

沙箱是服务器上为脱敏/恢复操作准备的受控工作区，用一个共享 PIN 保护：

- 首次进入可设置一次性 PIN；之后沙箱进入锁定状态，文件操作前需要解锁。
- PIN 输错会累计失败次数，连续多次错误会触发短时限制，页面会提示“验证过于频繁，请稍后再试”；限制过后用正确 PIN 仍可解锁。
- 可以手动锁定、解锁、清除 PIN。
- 这个共享 PIN 只保护沙箱操作，不是登录凭据，也不是用户身份。服务器上所有会话共享同一个沙箱和同一个 PIN。

## 6. 支持格式与限制

- 格式：TXT、Markdown、CSV、Excel（.xls/.xlsx）、DOCX、PPT（旧版）、PPTX、PDF。
- 单批次最多 100 个文件，单文件最大 500 MB，批次总大小最大 2 GB。
- PDF 最多 1000 页。

## 7. 扫描件（图片型）PDF

没有文字层的扫描 PDF 会自动走 OCR 识别，通常需要几十秒到两分钟，请耐心等待预览/批次状态更新。

若页面提示「OCR 不可用」：说明服务器尚未安装 OCR 组件。请联系管理员安装，不要自行安装。OCR 由管理员在服务器上统一配置一次，浏览器端无需、也无法自行安装。

## 8. 常见错误码

在「错误与重试」页看到的错误码是安全的最小说明，不含原文或内部路径：

| 错误码 | 含义 |
|---|---|
| `INPUT_ENCRYPTED` | 文件已加密，需先解密再提交 |
| `INPUT_CORRUPTED` | 文件结构损坏或格式不受支持 |
| `INPUT_NO_CONTENT` | 文件本身没有可提取的内容 |
| `INPUT_LIMIT_EXCEEDED` | 超出大小/页数/像素等限制 |
| `OCR_COMPONENT_REQUIRED` / `OCR_COMPONENT_INVALID` | OCR 未安装或未就绪，联系管理员 |
| `OCR_NO_TEXT` | 扫描件识别不到任何文字 |
| `OCR_TIMEOUT` | OCR 处理超时，可重试 |
| `LEGACY_CONVERTER_UNAVAILABLE` | 旧版 PPT 转换组件未就绪，联系管理员 |

更完整的排障说明见 [DEPLOYMENT.md](./DEPLOYMENT.md#8-就绪检查与排障)（面向管理员）。

## 8.1 运行时异常的白话处理

- 页面顶部显示「未连接」或提示“请确认服务器 Runtime 已启动”：
  说明浏览器暂时连不上服务器处理服务。这通常是暂时现象，一般不需要重新上传；等服务器恢复后页面会自动重新连接，此前已提交的批次结果仍在服务器上。若长时间无法恢复，联系管理员。
- 旧版 PPT 提示 `LEGACY_CONVERTER_UNAVAILABLE`：
  服务器没有安装 LibreOffice 转换组件，联系管理员安装后重启，不要自行处理。
- 扫描件提示 `OCR_TIMEOUT`：
  OCR 处理超时，可稍后重试；仍超时联系管理员。
- `OCR_COMPONENT_REQUIRED` / `OCR_COMPONENT_INVALID`：
  OCR 未安装或未就绪，联系管理员，见第 7 节。

## 9. 上传脱敏结果到 FileBay（服务器管理的私有仓库）

FileBay 是服务器管理员预先配置的固定目标（HTTPS 私有仓库）。浏览器
无法修改目标地址、访问令牌、owner 或仓库，也看不到令牌本身。若管理员尚未
配置，上传功能会显示“未配置”或“配置无效”，请联系管理员配置并重启服务，
不要自行填写任何地址或令牌；FileBay 未配置不影响脱敏、恢复、日志或沙箱功能。

### 9.1 查看状态与测试连接（`/gitea`）

1. 打开「FileBay 上传设置」页（`/gitea`），查看配置状态：
   - 已配置：显示目标地址（HTTPS）、目标仓库（owner/repo）和“访问令牌：已配置”。
   - 未配置 / 配置无效：上传功能被禁用，联系管理员。
2. 状态为“已配置”时可点击「测试连接」，确认目标地址可达、仓库是否存在。
3. 若测试提示目标仓库不存在，可点击「创建私有仓库」，并再次确认目标地址与
   owner/repo 后创建；只会创建私有仓库，不会创建公开仓库。

### 9.2 上传已完成产物（`/files` 文件管理）

1. 进入「文件管理」页，找到已完成（`Completed`）的批次，点击该批次的
   「上传到 FileBay」。
2. 弹出窗口中只会列出 Runtime 确认已完成（`Completed`）的脱敏 Markdown，
   每行显示文件名与服务器生成的远端路径；默认全选，可取消部分文件。
3. 点击「下一步」进入确认弹窗，核对：
   - 目标地址（HTTPS origin）、目标仓库（owner/repo）；
   - 每个文件的远端路径；
   - 提示“只会上传脱敏后的 Markdown 文件本身；不会上传原始文件、映射文件
     （`.cmap`）或反脱敏还原产物”。
4. 核对无误后点击「确认上传」。浏览器只提交所选产物的 ID，文件内容与远端
   路径由服务器读取和生成。
5. 上传结果按文件逐项显示成功或失败；失败项显示安全错误码，可回列表重试。

页面加载、处理完成、下载、恢复或取消确认时，都不会自动上传或自动访问
FileBay。上传只会发生在你主动点击“确认上传”之后。

### 9.3 删除结果文件与云端同步删除

在「文件管理」页删除结果文件时，可根据当前部署能力选择是否同步删除 FileBay 上的对应文件。

使用规则如下：

1. 先确认要删除的是已不再需要保留的脱敏结果
2. 删除前再次核对批次、文件名和远端路径
3. 如页面出现“同时删除 FileBay 云端文件”选项，勾选后会一起删除远端脱敏文件
4. 若未勾选，系统只删除当前服务端或本地记录，不会影响 FileBay 中的远端文件

注意事项如下：

- 该操作只面向脱敏结果文件，不涉及原始文件或映射文件
- 是否显示云端同步删除选项，取决于 FileBay 是否已完成配置并具备对应权限
- 若本地删除成功但云端删除失败，页面会给出明确提示，此时需由管理员继续排查 FileBay 连接、令牌或仓库状态
- FileBay 删除能力属于受控运维动作，不属于本次客户开放的正式业务 API 范围

### 9.4 FileBay 常见提示

| 提示 / 错误码 | 含义 | 处理 |
|---|---|---|
| 未配置 / `FILEBAY_NOT_CONFIGURED` | 管理员尚未配置四项环境变量 | 联系管理员配置后重启服务 |
| 配置无效 / `FILEBAY_CONFIG_INVALID` | 四项未同时配置或格式非法 | 联系管理员检查后重启 |
| `FILEBAY_AUTH_FAILED` / `FILEBAY_CONNECTION_FAILED` | 令牌失效或目标不可达 | 联系管理员 |
| `FILEBAY_REPOSITORY_NOT_FOUND` | 目标仓库不存在 | 在 `/gitea` 显式创建私有仓库 |
| `FILEBAY_UPLOAD_DENIED` | 所选文件不在上传白名单 | 只选择已完成脱敏 Markdown 的产物 |

## 10. 单系统用户与共享状态说明

本版本按“单一系统用户”交付，没有注册、登录、账号列表或角色。能访问该内网页面的
所有浏览器会话共享同一台服务器的状态：

- 沙箱/PIN：同一个服务器沙箱目录、同一个共享 PIN。共享 PIN 只用于锁定或解锁
  沙箱操作，不是登录凭据，也不是用户身份。
- FileBay：同一套管理员配置的目标地址、令牌、owner 和仓库，所有会话共享。

以上共享状态不构成登录、RBAC、管理员/普通用户区分或多租户隔离；本版本仍只供
企业内网使用，需在客户网段内才能访问，不要将部署地址对外公开。
