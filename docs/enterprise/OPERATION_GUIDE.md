# CheersAI Vault 企业版 · 操作手册

面向浏览器端使用者的简易指南。部署与技术细节见 [DEPLOYMENT.md](./DEPLOYMENT.md)（面向管理员）。

## 1. 打开企业端

由管理员告知的地址在浏览器打开，通常是 `http://127.0.0.1:5173`（仅本机访问，不支持远程/多用户）。

## 2. 提交文件

1. 点击左侧「批量提交」。
2. 选择要脱敏的文件（支持格式与限制见第 6 节）。
3. 勾选需要识别的规则（手机号、邮箱、身份证号等）。
4. 点击提交，进入「处理日志」查看进度。

## 3. 查看结果

处理日志中每个批次显示状态：

- **已完成**：全部文件成功。
- **部分失败**：批次内有文件成功、有文件失败，点「查看详情」逐个查看。
- **失败**：全部文件失败，点「查看详情」→「查看错误与重试」可看到具体原因（错误码 + 一句话说明），可点「重新处理」重试。

## 4. 下载与恢复

- 成功的文件在批次详情页可「下载 Markdown」，得到脱敏后的文档。
- 需要看回原文时，进入「反脱敏」页面，勾选已完成的产物，点「开始反脱敏」即可下载还原后的文件。
- **映射数据（`.cmap`）只保存在服务器内部，页面上没有下载入口**，不会被导出。

## 5. 处理日志：搜索与筛选

处理日志页支持按批次 ID 前缀搜索、按状态筛选（全部/处理中/已完成/部分失败/失败），点击「清空条件」恢复完整列表。

## 6. 支持格式与限制

- 格式：TXT、Markdown、CSV、Excel（.xls/.xlsx）、DOCX、PPT（旧版）、PPTX、PDF。
- 单批次最多 100 个文件，单文件最大 500 MB，批次总大小最大 2 GB。
- PDF 最多 1000 页。

## 7. 扫描件（图片型）PDF

没有文字层的扫描 PDF 会自动走 OCR 识别，通常需要几十秒到两分钟，请耐心等待处理日志更新。

若页面提示「**OCR 不可用**」：说明服务器尚未安装 OCR 组件。**请联系管理员安装，不要自行安装**——OCR 由管理员在服务器上统一配置一次，浏览器端无需、也无法自行安装。

## 8. 常见错误码

在「错误与重试」页看到的错误码是安全的最小说明，不含原文或内部路径：

| 错误码 | 含义 |
|---|---|
| `INPUT_ENCRYPTED` | 文件已加密，需先解密再提交 |
| `INPUT_CORRUPTED` | 文件结构损坏或格式不受支持 |
| `INPUT_NO_CONTENT` | 文件本身没有可提取的内容 |
| `INPUT_LIMIT_EXCEEDED` | 超出大小/页数/像素等限制 |
| `OCR_COMPONENT_REQUIRED` / `OCR_COMPONENT_INVALID` | OCR 未安装或未就绪，联系管理员 |
| `OCR_NO_TEXT` | 扫描件识别不到任何文字 |
| `OCR_TIMEOUT` | OCR 处理超时，可重试 |
| `LEGACY_CONVERTER_UNAVAILABLE` | 旧版 PPT 转换组件未就绪，联系管理员 |

更完整的排障说明见 [DEPLOYMENT.md](./DEPLOYMENT.md#就绪检查与排障)（面向管理员）。
